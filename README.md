# ReportCard Pro: downloads

Offline report cards for Nigerian nursery, primary and secondary schools. By Fidelis Chukwunyere (@Fidelcmedia).
Your data never leaves your computer.

**[Download the latest version](../../releases/latest)**

| Your computer | File to download |
|---|---|
| Windows 10 / 11 | `ReportCardPro-Setup-*.exe` |
| Mac (M1/M2/M3/M4) | `ReportCardPro-*-macos-arm64.pkg` |
| Mac (Intel) | `ReportCardPro-*-macos-x64.pkg` |
| Linux (any) | `ReportCardPro-*-linux-x64-setup.run` |
| Debian / Ubuntu | `reportcardpro_*.deb` |

## Plans
| Plan | Students per import and per run | Exports |
|---|---|---|
| Free Forever (no licence needed) | 10 | Individual PDFs |
| Basic | 30 | Individual PDFs |
| Standard | 100 | Individual PDFs, combined PDF, ZIP |
| Premium | Unlimited (depends on your computer) | Individual PDFs, combined PDF, ZIP |

Imports and exports are unlimited in number on every plan, and customer support is included with every plan.

**A licence is tied to one computer** (for security). Send the *Computer ID* from the app's License page to get your licence file; moving to a new computer
is a short, documented process: see the [User Guide](USER_GUIDE.md).

**How to use the app:** read the [User Guide](USER_GUIDE.md), which has screenshots.
